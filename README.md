# ConectaDev

Landing page responsiva para divulgar serviços de desenvolvimento web.

## Arquivos

- `index.html`: conteúdo da página
- `style.css`: visual responsivo
- `script.js`: ano automático no rodapé
- `assets/`: artes quadradas para publicações no LinkedIn

## Visualizar

Abra `index.html` em um navegador.

## Publicar no GitHub

Envie todos os arquivos e a pasta `assets` para a raiz do repositório ConectaDev.
